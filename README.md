# Octopush Contractors

## Overview
Construction Supply Chain & Inventory Management System. Features include PO tracking, Real-time inventory, Heavy equipment management, and Role-based dashboards.

## Stack
- Next.js (App Router)
- Supabase (PostgreSQL & Auth)
- Prisma ORM
- Tailwind CSS

## Getting Started
1. Run `npm install`
2. Run `npm run dev`
